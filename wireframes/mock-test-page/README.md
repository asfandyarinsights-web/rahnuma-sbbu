# Mock Test Page Wireframes

## Purpose

Document the desktop and mobile designs for Rahnuma's timed practice mock test.

## Desktop

* `desktop.png` — Desktop mockup board showing the test experience.

## Mobile

* `mobile/01-before-starting.png` — Test overview before starting.
* `mobile/02-test-in-progress.png` — Active test question and timer.
* `mobile/03-results.png` — Results after submission.
* `mobile/04-submission-dialog.png` — Submission confirmation.
* `mobile/05-question-navigator.png` — Expanded question navigator.
* `mobile/06-mobile-menu.png` — Mobile navigation menu.

## Key Design Decisions

* Display one question at a time.
* Show the timer and question progress during the test.
* Allow question navigation and answer selection.
* Confirm submission before ending the test.
* Show correct, incorrect, and unanswered counts in results.
* Use mobile-friendly controls and responsive layouts.
* Mark test duration and question count as illustrative until officially verified.
* Clearly identify the mock test as practice, not an official SBBU examination.
