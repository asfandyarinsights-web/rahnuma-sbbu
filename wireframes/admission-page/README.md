# Admission Page Wireframes

## Overview

This folder contains the desktop and mobile wireframes for Rahnuma SBBU's Admission page.

The page is designed to help students understand the general admission journey and find relevant entrance-test preparation resources.

## Design Files

* `desktop.png` — Desktop Admission page design.
* `mobile.png` — Mobile Admission page design.

## Page Structure

1. Page header and introduction
2. Admission overview cards
3. Step-by-step admission process
4. Entrance-test preparation links
5. Official information notice
6. Shared Rahnuma footer

## Design Decisions

* Follow Rahnuma's established design system.
* Use Lexend for headings and Inter for body text and interface elements.
* Maintain consistent colors, spacing, card styles, and navigation.
* Use a single-column layout on mobile.
* Keep admission information concise and easy to scan.
* Direct students toward relevant Rahnuma preparation resources.
* Clearly distinguish Rahnuma from the official university website.

## Information Accuracy

Admission dates, eligibility criteria, fees, application instructions, and merit information must be verified using official SBBU sources before publication.

Do not present unverified information as official university guidance.

## Responsive Design

* Desktop and mobile layouts are documented separately.
* Mobile layout supports natural vertical scrolling.
* Interactive elements should have accessible touch targets.
* Horizontal scrolling should not be required.
