# Practice Questions Page Wireframes

## Purpose

These wireframes define the desktop and mobile layouts for Rahnuma's Practice Questions page.

## Included Designs

* `desktop.png` — Desktop layout
* `mobile.png` — Mobile layout

## Key Design Decisions

* Display one practice question at a time.
* Allow students to filter questions by subject.
* Provide multiple-choice answer options.
* Show the correct answer and explanation after an answer is submitted.
* Provide Previous and Next Question navigation.
* Maintain Rahnuma's shared design system and responsive navigation.
* Support mobile screens without horizontal scrolling.

## Status

Design approved. Ready for implementation planning.
